## 📖 Learning Path

### Week 1-3: Level Easy (Fundamentals)
Start with these projects to build your foundation:
1. ✅ Portfolio Website - Learn HTML, CSS, JavaScript, Tailwind
2. ✅ Todo List - Learn React, useState, localStorage
3. ✅ Weather App - Learn API integration, Axios, async/await
4. ✅ Movie Database - Learn React hooks, pagination, filtering

**Time:** 3-4 weeks  
**Skills:** Frontend fundamentals, React basics, API integration

---

### Week 4-14: Level Sedang (Backend Introduction)
Move on to these projects:
5. 📦 Expense Tracker - First database! SQLite
6. 📦 Markdown Notes - MySQL, relational database
7. 📦 IoT Dashboard - PostgreSQL, complex queries
8. 📦 Chat App - Real-time communication, PostgreSQL + Redis
9. 📦 Blog CMS - MongoDB, flexible schema
10. 📦 Kanban Board - Drag-drop, real-time updates
11. 📦 Social Media Feed - GraphQL, complex relationships
12. 📦 Quiz Platform - Traditional relational structure

**Time:** 8-10 weeks  
**Skills:** Backend fundamentals, databases, authentication, real-time features

---

### Week 15-26: Level Advanced (System Design)
Master these advanced projects:
13-20. 🚀 Advanced projects covering microservices, AI integration, distributed systems

**Time:** 12-16 weeks  
**Skills:** System architecture, microservices, scalability, AI/ML integration

## 🗄️ Database Technologies Covered

Progression from simple to complex:
- **SQLite** - File-based, learning database
- **MySQL** - Traditional relational database
- **PostgreSQL** - Advanced SQL, production-grade
- **MongoDB** - NoSQL, flexible schema
- **Redis** - In-memory caching
- **Cassandra** - Distributed, time-series
- **InfluxDB** - Time-series optimization
- **MLflow** - Model tracking
